# SortingMassive
### Описание проекта:
Это приложение Windows Forms демонстрирует работу различных алгоритмов сортировки с визуализацией результатов. Программа включает:
4 классических алгоритма сортировки
3 специализированных алгоритма для конкретных типов данных
Генераторы тестовых данных для каждого типа сортировки

### Функционал
Типы массивов
Числовой массив - произвольные целые числа
Бинарный массив - только значения 1 и 2
Массив флагов - символы W (White), B (Blue), R (Red)
Массив Хогвартса - символы G (Gryffindor), H (Hufflepuff), R (Ravenclaw), S (Slytherin)

### Алгоритмы сортировки

Алгоритм		Сложность		Применение
Bubble Sort		O(n²)			Числовые массивы
Insertion Sort		O(n²)			Числовые массивы
Merge Sort		O(n log n)		Числовые массивы
Quick Sort		O(n log n)		Числовые массивы
SortN2	O(n)		O(n)			Бинарные массивы
SortFlag		O(n)			Массивы флагов
SortHogwarts		O(n)			Массивы Хогвартса


### Использование:

Выберите тип массива, нажав соответствующую кнопку
Задайте параметры генерации:
Для числового массива: минимальное и максимальное значение, размер
Для других массивов: только размер
Нажмите "Сгенерировать"
Выберите алгоритм сортировки (для числовых массивов)
Нажмите "Отсортировать"
Результат отобразится в таблице справа
